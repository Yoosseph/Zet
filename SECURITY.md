# Security policy

Zet is in early development. Security fixes are made on the main branch; no older release branch
is currently maintained.

Please do not post a suspected vulnerability, a secret, or real user data in a public issue. Use
GitHub's **Report a vulnerability** option in the repository's Security tab. If that option is not
available, open an issue asking for a private reporting channel without including exploit details.

Include the affected version or commit, a minimal reproduction using synthetic data, and the
impact. The maintainers will acknowledge the report and coordinate a fix and disclosure.
