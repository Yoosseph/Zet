# Code of conduct

Be respectful and constructive in issues, pull requests, and discussions. Critique ideas and
code, not people. Harassment, personal attacks, discrimination, and publishing someone else's
private information are not acceptable.

Maintainers may edit or remove contributions that violate these standards and may limit
participation when necessary. To report a problem, open an issue with only the information you
are comfortable sharing publicly. For a sensitive report, ask the maintainers for a private
contact channel without posting the details in the issue.
