Know when to ask a human.

Zet adds a sure or unsure decision to Laya's answers about text. It learns from labeled examples which answers can be used automatically and which should go to review.

Explore the code → Read the benchmark
01 · Answer

Laya predicts

For example, it chooses a topic for a message.

02 · Check

Zet checks scores

A rule learned from labeled examples marks the answer sure or unsure.

03 · Route

Use or review

Sure answers run automatically. Unsure ones go to a person.

Measured on a public dataset

Zet flagged 41 of Laya's 45 mistakes for review.

In a six-topic test of 350 requests, Zet still accepted 227 automatically. It sent 123 to review, including 82 that Laya had right, and let four wrong answers through.

The dataset already had human labels. No person performed the reviews in this test. See the method, sources, and limits →
