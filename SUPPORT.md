# Support

For setup questions and suspected bugs, search the existing GitHub issues first, then open an
issue with your Python version, operating system, steps to reproduce, and the relevant error.
Use synthetic input: do not attach customer emails, task files, tokens, or full local logs.

The [run guide](docs/HOW-TO-RUN.md) covers installation, model checks, and common problems.
For security issues, follow [SECURITY.md](SECURITY.md).
